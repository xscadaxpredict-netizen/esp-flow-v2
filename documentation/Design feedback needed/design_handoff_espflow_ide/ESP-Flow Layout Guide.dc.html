Region reference

FIG. 1 — DETAIL
1 · Window title bar
App-launcher grid for sibling platform apps (SCADA, integration, BI), the ESP-Flow wordmark, then BottlingLine_v3 – [Prog0 : Ladder Diagram]. Right side carries the artboard/scenario switcher, theme toggle and save state. There is no login — the user arrives authenticated with a project open.
2 · Menu bar
Exactly eight menus: File, Edit, View, Compile, PLC, Tools, Window, Help. The command palette (Ctrl+Shift+P) sits at the right as a visible affordance, never replacing the menus.
3 · Toolbars
Five separated groups across two 28px rows — STD (file, undo/redo, clipboard, find), LADDER (contacts, coils, function block, wires, networks), PLC (connect, download, upload, run, stop, monitor, force), COMPILE (compile, rebuild, check, error navigation, cross-reference), VIEW (zoom, grid, comments, panels). 16px line-art icons, labelled group separators, tooltips on hover.
4 · Project panel
Dockable tree: Hardware Configuration, Network Configuration, Global Symbols, Programs (Prog0 LD, Prog1 ST), Function Blocks, Tasks, Device Monitor Tables. Distinct icon per node type, expand/collapse at every level, selection state, right-click context menu.
5 · Editor tabs
Open documents — Prog0 [Ladder], MotorStarter [FB], Device Table 1, Monitor Chart. The dot on the active tab marks unsaved changes; each tab closes independently.
6 · Breadcrumb & mode strip
Project / Programs / Prog0 / Network N, the active tool hint, and the edit-mode chip (OFFLINE EDIT / ONLINE MONITOR). This is where the editor tells you what a click will do next.
7 · Local symbols
Collapsible, resizable declaration table: Class (VAR / VAR_INPUT / VAR_OUTPUT), Identifier, Address, Data Type, Initial Value, Comment. It is the single source for symbol pickers on the canvas and in Properties.
8 · Ladder canvas
The document. Two power rails, numbered networks each with a comment line, contacts and coils showing symbol above and address below, function blocks with named pins. Selection ring with handles, insertion caret, diagnostic underlines on offending elements. Coils always sit against the right rail; branches wrap their parent element and grow with it.
9 · Library panel
Three collapsible groups — Standard Library (timers, counters, edge detection, bistables, math, comparison, bit ops, conversion), ESP-Flow Library (WiFi, MQTT, analog read, PWM, I2C, NTP), User Library (MotorStarter, TankFill). Items drag onto the canvas with a drop indicator.
10 · Properties panel
Context-sensitive to the canvas selection. Symbol is chosen from the declared local symbols via a filtering picker; Address and Data Type are read-only and follow the symbol; Contact Type and Comment are editable. Tabbed with Watch.
11 · Message panel
Dockable and resizable, three tabs. Compile: determinate progress through Validating → Generating C++ → Compiling → Linking → Ready to flash, with elapsed time and streaming compiler output. Problems: Severity / Code / Message / Location, filterable by severity and source, rows jump to the offending element. Search Results: cross-reference output with read/write per use.
12 · Status bar
Left to right: edit mode (Insert / Overwrite), cursor location, connection chip with status dot (Connected — ESP32-S3 on COM4), PLC state (RUN / STOP), live scan time, compile state, then zoom.
Shell region Work edit area (5–8) Panels 4, 9, 10 and 11 are dockable and resizable via splitter handles. Minimum supported viewport 1440×900.
