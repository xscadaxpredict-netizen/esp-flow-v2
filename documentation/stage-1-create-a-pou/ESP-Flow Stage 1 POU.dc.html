Open questions — answered
A program with no task is allowed. Leaving Task empty keeps the POU compilable but unscheduled; the tree writes unscheduled where the task name would go, in the same slot that carries LD, and the program does not appear under any task. The hint under the Task field says so before the engineer commits.
Rename… reuses this dialog, in its Properties form (1g) with focus in Name — not in-place tree editing. The same validation, the same written reasons, and one place where a name is judged. In-place editing would have to grow its own error surface inside a 20px tree row.
Deferred: what the compiler accepts. Per ADR-001 the browser only renders the verdict, so 1d and 1e fix where the message sits and how it reads; the rules quoted are ISPSoft's, for realism only.
